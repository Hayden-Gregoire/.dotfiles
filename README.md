# My Dotfiles Repository

## Files and Scripts
- **etc/bashrc_custom**: Contains custom environment variables, aliases, and functions.
- **bin/linux.sh**: Sets up the environment, custom `.nanorc`, and `.bashrc` configurations.
- **bin/cleanup.sh**: Reverts the changes made by `linux.sh`.
- **Makefile**: Automates the process of running `linux.sh` and `cleanup.sh`.

## Usage
- Run `make` to set up the environment.
